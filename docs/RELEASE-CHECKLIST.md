- [x] **VERIFIED at baseline** — Shared semantic suite actually runs against memory and PostgreSQL. Real isolated PostgreSQL 17.11 is mandatory in the clean matrix, with zero skipped tests. - [x] **VERIFIED** — Concurrent claims have one winner; opposite dependency additions cannot both commit. `ClaimRacingDependencyEditNeverRunsWorkWithUndonePrerequisite` checks 25 races per store: running work never retains an undone prerequisite, and a winning dependency keeps work open. - [x] **VERIFIED** — Stopped/reclaimed executions cannot append graph output: shared fencing tests and `TestStaleExecutionStopsOldWorker` assert `stale_execution`; toolkit and stdio tests enforce producer binding and host authorization. - [x] **VERIFIED** — PostgreSQL rollback at `after_nodes`, `after_edges`, `before_events`, `after_events`, `before_commit`; rejected restore leaves zero rows in all seven tables. Replay returns original IDs/revision after graph closure. Failed requests reserve neither event nor request key. Fault injection is PostgreSQL-only.
- [x] **VERIFIED** — Acceptance tests assert recursive freshness, exact reviewed closure/resources, unchanged unrelated goals, stale dependent acceptances, historical preservation and a single criteria-change revision. - [x] **VERIFIED** — Projection tests independently encode full UTF-8 envelopes at exact/one-byte-under boundaries; assert mandatory origin/goals/assignment, omissions, whole-node statements and retrieval paths.
