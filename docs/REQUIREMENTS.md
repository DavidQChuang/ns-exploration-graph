## Contract decisions and remaining audit gates

The original contract questions are retained here with their dispositions; none is silently removed:

- **Acceptance result naming:** Decision 002 defines `reviewed_evidence` as exact node/revision references plus `support_edge_ids` and `reviewed_resource_ids`; toolkit maps host `node_id` to model `id`. Runtime tool and snapshot closure assertions cover these fields.
- **MCP pinning:** SDK v1.8.0 and protocols 2026-07-28 / 2025-11-25 are declared in README and checked by adapter tests. Contract approval is recorded in Decision 012; artifact sign-off is separate.
- **Freshness in reads:** Decision 002 and `graph/index.go` use recursive exact-revision freshness (`fresh`, `stale`, `not_applicable`); scoped/full-read parity tests prevent the optimization changing semantics.
- **Graph creation revision:** Decision 002 fixes creation/event revision 1; import also starts its own event history at 1. Shared replay/event/restore tests assert it.
- **Dependency eligibility:** done work is terminal; dependency edits require an open dependent. Shared concurrent claim/edit tests prove a running item cannot retain an undone prerequisite through a racing edit.
- **Identity characters:** Decision 010 defines the 200-character identity limit as valid UTF-8 Unicode code points; byte budgets remain serialized UTF-8 bytes. Exact ASCII/non-ASCII boundary tests run against both stores.

Named runtime/fixture gaps were corrected and their assertions reviewed at ba4769a: host lifecycles, shared URI validation, UUID portability and the full PLAN G4 second stage. Final exact-source clean verification and release finalization are tracked by the PARTIAL rows/checklist. Hosted GitHub orchestration remains unexecuted; clean local runs use the same CI verification script, enforce required PostgreSQL/Python, and include race detection. Model smoke tests and M3 are optional/outside M1+M2. Linear aggregate costs are documented measured limits, not silently removed requirements or promises of unlimited production scale.
